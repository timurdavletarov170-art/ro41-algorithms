## 1. Сортировка выбором (Selection Sort)

Дано: `a = {5, 2, 9, 1, 7}`

| Шаг `i` | Индекс min | Состояние массива после обмена | Кол-во сравнений |
| :---: | :---: | :--- | :---: |
| `0` | `3` (число 1) | `{1, 2, 9, 5, 7}` | 4 |
| `1` | `1` (число 2) | `{1, 2, 9, 5, 7}` | 3 |
| `2` | `3` (число 5) | `{1, 2, 5, 9, 7}` | 2 |
| `3` | `4` (число 7) | `{1, 2, 5, 7, 9}` | 1 |

**Всего сравнений:** $4 + 3 + 2 + 1 = 10$.

## 2. Сортировка вставками (Insertion Sort)

Дано: `a = {4, 3, 2, 1}`

| Шаг `i` | Ключ `key` | Кол-во сдвигов | Массив после вставки |
| :---: | :---: | :---: | :--- |
| `1` | `3` | 1 | `{3, 4, 2, 1}` |
| `2` | `2` | 2 | `{2, 3, 4, 1}` |
| `3` | `1` | 3 | `{1, 2, 3, 4}` |

* **Суммарное число сдвигов:** $1 + 2 + 3 = 6$.
* **На уже отсортированном массиве из 4 элементов:** алгоритм выполнит **3 сравнения** (по одному на каждом шаге `i = 1, 2, 3`, сдвигов не будет).

## 3. Бинарный поиск (Binary Search)

Массив: `{1, 3, 5, 7, 9, 11, 13}`

### Поиск `x = 7`
| Шаг | `lo` | `hi` | `mid` | `a[mid]` | Действие |
| :---: | :---: | :---: | :---: | :---: | :--- |
| 1 | 0 | 6 | 3 | 7 | Найдено совпадение `a[3] == 7`, возврат `3` |

### Поиск `x = 6`
| Шаг | `lo` | `hi` | `mid` | `a[mid]` | Действие |
| :---: | :---: | :---: | :---: | :---: | :--- |
| 1 | 0 | 6 | 3 | 7 | `7 > 6`, сдвигаем правую границу: `hi = 2` |
| 2 | 0 | 2 | 1 | 3 | `3 < 6`, сдвигаем левую границу: `lo = 2` |
| 3 | 2 | 2 | 2 | 5 | `5 < 6`, сдвигаем левую границу: `lo = 3` |

* **Завершение поиска `x = 6`:** границы пересеклись (`lo = 3 > hi = 2`), цикл останавливается, элемент не найден (возврат `-1`).
* **Результат `LowerBound(6)`:** вернёт индекс **`3`** (первый элемент $\ge 6$, то есть число `7`).
