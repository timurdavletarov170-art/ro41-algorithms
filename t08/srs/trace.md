## Задание 1. Методы `Trim()` и `Split(';')`

Дано: `s = "  Ахметов Ерлан;85 "`

* **Вызов `s.Trim()`**: убирает 2 пробела в начале и 1 пробел в конце. Получаем строку `"Ахметов Ерлан;85"` (длина 16 символов).
* **Вызов `Split(';')`**: делит полученную строку по разделителю `;` на массив из двух элементов:

| Номер в массиве | Значение подстроки | Количество символов (`Length`) |
| :---: | :--- | :---: |
| `0` | `"Ахметов Ерлан"` | 13 |
| `1` | `"85"` | 2 |

## Задание 2. Разбор строки и `int.TryParse`

Дано: `line = "Иванов Пётр;70;85;x"`

После `Split(';')` получаем массив из 4 частей. Трассировка `int.TryParse`:

| Индекс | Подстрока | Результат `TryParse` | Выходной параметр `out` | Комментарий |
| :---: | :--- | :---: | :---: | :--- |
| `0` | `"Иванов Пётр"` | `false` | `0` | ФИО (не число) |
| `1` | `"70"` | `true` | `70` | Корректное число |
| `2` | `"85"` | `true` | `85` | Корректное число |
| `3` | `"x"` | `false` | `0` | Ошибка: не цифра |

**Результат `TryParseScores`:** метод вернёт `false`, так как на индексе `3` находится строка `"x"`, которую невозможно преобразовать в `int`.

## Задание 3. Работа `string` и `StringBuilder` в цикле

Цикл: `for (int i = 0; i < 4; i++)`

| Итерация | Значение `s` (`s += i`) | Создано объектов `string` | Буфер `sb` (`sb.Append(i)`) | Создано объектов `StringBuilder` |
| :---: | :--- | :---: | :--- | :---: |
| Старт | `""` | 1 (пустая строка) | `""` | 1 (экземпляр `sb`) |
| `i = 0` | `"0"` | +1 | `"0"` | 0 |
| `i = 1` | `"01"` | +1 | `"01"` | 0 |
| `i = 2` | `"012"` | +1 | `"012"` | 0 |
| `i = 3` | `"0123"` | +1 | `"0123"` | 0 |

* **Итог для `string`:** создаётся **5 объектов** строк (1 начальный `""` и по 1 новому на каждом из 4 шагов цикла).
* **Итог для `StringBuilder`:** создаётся **1 объект** `StringBuilder` (символы записываются во внутренний буфер без создания новых объектов).

## Задание 4. Почему `s.ToUpper()` без присваивания не меняет строку `s`?

В C# строки (`string`) **неизменяемы (immutable)**. Метод `ToUpper()` не меняет исходную строку в памяти, а создаёт и возвращает **новую строку** с большими буквами. Без присваивания (`s = s.ToUpper()`) результат теряется, а `s` продолжает ссылаться на прежнюю строку.
